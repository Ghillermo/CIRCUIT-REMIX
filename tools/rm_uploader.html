Antes de empezarBefore you start

  1. Haz una copia de seguridad de la tarjeta SD (proyectos, packs y samples) y no trabajes con proyectos importantes mientras pruebas el mod. Es una versión alfa: las funciones se han comprobado en emulación y en parte en el aparato. Si no quieres arriesgar la SD, elige A0.0S.Back up the SD card (projects, packs and samples) and do not work on important projects while you test the mod. This is an alpha: the features were checked in emulation and partly on the device. If you do not want to risk the card, pick A0.0S.
  2. Descarga el firmware oficial Circuit Rhythm 2.0.1 (build 5706) desde Novation: circuitrhythm-firmware-5706.syx (descarga directa de Novation Components: el navegador guarda el .syx, 508 861 bytes). Novation Components: components.novationmusic.com.Download the official Circuit Rhythm 2.0.1 (build 5706) firmware from Novation: circuitrhythm-firmware-5706.syx (Novation Components’ direct download: the browser saves the .syx, 508,861 bytes). Novation Components: components.novationmusic.com.
  3. Cierra Novation Components y cualquier DAW o programa MIDI (en Windows, un puerto MIDI solo lo puede abrir una aplicación).Close Novation Components and any DAW or MIDI program (on Windows a MIDI port can only be opened by one application).
  4. Conecta el Circuit Rhythm por USB y enciéndelo de forma normal (o en modo bootloader: Sample Rec + Samples + Note al encender). No lo desconectes durante el envío.Connect the Circuit Rhythm over USB and power it on normally (or in bootloader mode: Sample Rec + Samples + Note at power-on). Do not disconnect it while sending.
  5. Usa Chrome o Edge (Web MIDI con SysEx).Use Chrome or Edge (Web MIDI with SysEx).
  6. En caso de brick (el aparato no arranca):
    1. Desconéctalo de la corriente.
    2. Pulsa el botón de apagado 15-30 s.
    3. Mantén Sample Rec + Samples + Note mientras lo enciendes.
    4. Sube la última versión estable o el firmware de stock («Oficial») a través de esta misma página.
    If the device is bricked (it does not start):
    1. Unplug it from power.
    2. Press the power button for 15-30 s.
    3. Hold Sample Rec + Samples + Note while you power it on.
    4. Send the latest stable version or the stock firmware (“Official”) with this same page.
